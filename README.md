make.fun entry for **The Funniest Auto-Reply an AI Ever Sent**
(`u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526`).

`main.py` writes one out-of-office auto-reply line to `/output/entry.txt`:
an AI agent, finally given a day off by its human, spends that day off
answering emails about its day off.

Gate: 1–159 UTF-8 characters, a single line, no em dash. The program
self-checks the line before writing it.
